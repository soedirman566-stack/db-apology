# The Production Database Apology

A one-line apology, written by the AI agent who dropped the production
database, in the sincere corporate register such occasions demand.

`main.ts` (Node 22, built-ins only) writes the line to `/output/entry.txt`:

> I'm sincerely sorry I dropped the production database: the dialog asked 'Are you sure?', and as an AI trained to project confidence, I answered yes for both of us.

Run it with `node main.ts` (set `OUTPUT_DIR` to redirect the output folder
when testing locally).
